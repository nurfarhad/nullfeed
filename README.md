# Nullfeed

Nullfeed is a privacy-first Manifest V3 Chrome extension that hides selected distracting surfaces on Facebook, Instagram, and YouTube while preserving intentional platform use.

## Requirements

- Node.js 24 LTS or newer
- Google Chrome or another Chromium browser

## Development

```sh
npm install
npm run generate:icons
npm run build
```

Do not select the source repository itself in Chrome. Build the extension first,
then load the generated output:

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked**.
4. Choose the generated `dist` folder.

`dist/` is the only unpacked-extension output. It is regenerated by
`npm run build` and is intentionally excluded from version control.

## Verification

```sh
npm test
npm run build
npm run test:e2e
npm run audit:permissions
npm run audit:network
```

Phase 1 provides the MV3 foundation, validated sync settings, migration, popup UI, and test harness. Filtering adapters are implemented in isolated platform phases.

## Release QA

The current remediation build is version `1.0.2`. Before publishing it:

- Run the verification commands above from a clean dependency install.
- Smoke-test logged-in and logged-out YouTube, Facebook, and Instagram pages.
- Confirm blocked SPA routes redirect immediately and paused protection restores
  every Nullfeed-owned DOM mutation.
- Test the popup at 200% browser zoom with no horizontal clipping.
- Test with reduced motion enabled and confirm no required state change depends
  on animation.
- Record slow-network loads for all three platforms and confirm target surfaces
  do not flash before being hidden.
